The widget set

Built for the states nobody demos

Top-tier customers get no upgrade button at all. Single-plan products get no invented ladder. When the tier catalog is not mounted, the paywall still works from the 429 body alone. Unlimited draws no bar, because a full bar and an empty bar are both lies.

Money renders only where a field carries both an amount and an ISO code. Where the contract has no code — the spend summary, the subscription amount — the amount is withheld rather than guessed.

Loading is a skeleton, empty is a sentence, an outage is a quiet line with a working retry. No billing surface in this set has a red alarm state.
