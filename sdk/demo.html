ab0t-quota-ui — proof harness

Every panel below is the same SDK code fed a different consumer's config. No scenario shares a tier name, a resource name or a unit with any other. If the SDK contained a hardcoded ladder, cases C–F would render a plan that does not exist — the exact defect removed from the library in 0.6.3. Fixtures are the literal response shapes of /api/quotas/usage (engine.py:1155-1182), /api/quotas/tiers (setup.py:2361-2380), to_api_error() (models/responses.py:103-117) and billing/models.py. The same assertions run headlessly in node sdk/test_sdk.js.
