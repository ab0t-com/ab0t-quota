Read the money carefully. The balance figures render in the code the balance response itself carries. Spend this period shows no amount — the usage-summary contract has a total_cost but no currency field, and borrowing the balance's code for a different service's number is how a customer ends up looking at the wrong currency. The subscription amount is withheld for the same reason. Both gaps are ticketed (T-16) rather than filled in by the client.
